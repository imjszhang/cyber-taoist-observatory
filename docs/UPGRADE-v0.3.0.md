# 升级到 v0.3.0 · 分层工作空间

这次主要更新 UI、页面路由和前端测试。**宪章、Protocol、11 张卡牌资源、模型适配器、证据校验和 API 行为不变。** 引擎与 CLI 只更新发布版本标识。

## 已有 v0.2.1 用户

1. 停止旧服务器（运行它的终端按 `Ctrl+C`）。
2. 备份旧项目里的 `.env` 与 `.tao-lab`（或者 `TAO_LAB_HOME` 实际指向的目录）。
3. 将 v0.3.0 解压到新目录，不覆盖旧目录。
4. 将旧 `.env` 复制到新项目根目录。不要用 `.env.example` 覆盖自己的密钥、思考参数、token 与超时配置。
5. 在新 `.env` 中明确指定原来的数据目录：

   ```dotenv
   TAO_LAB_HOME="/你的旧项目绝对路径/.tao-lab"
   ```

   已经设置为正确绝对路径的，不需要改。**原先依赖默认目录或使用相对路径的，需要改成绝对路径**，否则新项目可能读取另一个空目录，让人误以为旧记录丢了。

6. 在新项目目录运行：

   ```bash
   npm run lab:start
   ```

7. 打开 `http://127.0.0.1:4174/lab`。原端口有自定义时，继续用旧端口。用 `Cmd+Shift+R`（macOS）或 `Ctrl+Shift+R` 强制刷新一次。

**同一数据目录只运行一个服务器实例。** 这一版没有后台数据迁移。旧 run 原样读取，打开页面不会重算或重新校验历史结果。

## 页面变化

| 原来 | 现在 |
| --- | --- |
| 打开就进入塞满内容的牌桌 | 先进入观测室，开始新观察或继续旧实验 |
| 六象、五牌、原文和洞见同时出现 | “信息 / 六象定位 / 洞见探索 / 本条手记”四个互斥阶段 |
| 洞见塞在弹窗里 | 独立阅读页，正文、替代解释、验证信号与反证条件按层次展开 |
| 全部原文和引文常驻 | 原文按需打开，逐段引文默认折叠，六象详情保留翻牌 |
| 设置放在长弹窗 | 独立设置页，接口和 CLI 的高级内容默认折叠 |
| 时间线后接所有 trace | 事件时间线、模型调用分别切换 |
| 11 张牌铺在同一页 | “六象定位 / 洞见之牌”两类牌库 |

旧链接 `/lab?run=RUN_ID` 仍打开对应实验的六象牌桌。新链接还保留 `view`、`obs`、`stage` 和 `note`，可以刷新或分享本机地址以重回同一阅读位置（不是跨机器分享服务）。链接中没有模型调用指令。

## 模型与故障恢复

`v0.2.1` 的逐段引文核验、显式模型重试、分阶段思考参数和等待时钟全部保留。

失败状态显示在当前牌桌阶段顶部。先尝试 **“重新校验旧返回 · 不调用模型”**；无法恢复时再显式确认模型重试。历史 trace 可以从“实验记录 → 模型调用”查看。

真实模型模式仍需在网页“设置 → 分析方式”显式选择。刷新页面默认回到演示 / 模板模式，避免在不知情时使用付费接口；已有真实结果仍会正常显示，不会被替换成模板。

## 回退

停止新服务，在旧目录重新启动 v0.2.1，并让它继续指向同一个已备份的数据目录。本版没有修改 run 存储结构；仍建议在升级前保留独立备份。UI 偏好（音效、减少动态）只在当前浏览器保存，不作为实验数据。

## 验证边界

浏览器界面在本次受限环境中使用渲染桥接验证，API 请求仍由真正的本机 Node 服务处理；没有修改浏览器网络策略。原生 EventSource 和 CLI 由 Node 测试覆盖。未用真实商业模型密钥测试，也未在 Safari、Firefox 或实体手机上测试。
