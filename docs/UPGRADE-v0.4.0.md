# 升级到 v0.4.0 · External Agent Link

## 保留旧数据

1. 停止旧版服务，备份 `.env` 与 `.tao-lab`（或 `TAO_LAB_HOME` 指向的目录）。同一数据目录只能运行一个服务。
2. 解压 v0.4.0 到新目录，不覆盖旧安装。
3. 复制旧 `.env`，不要用新版样例覆盖密钥、thinking、token 或超时参数。
4. 将数据路径设为原来的绝对路径：

```dotenv
TAO_LAB_HOME="/你的旧项目绝对路径/.tao-lab"
```

5. 在新目录启动：

```bash
npm run lab:start
```

浏览器打开原端口的 `/lab`，强制刷新。仍要求 Node.js 22.9+，无需 npm 安装依赖。

## 哪些保持不变

宪章、Protocol v0.1、来源文件、11 张插画及卡背/装饰、原证据校验、模型参数配置模块保持字节不变。已有 run 的 GET、页面导航、浏览、动画回放不改写实验；不会加载页面就重算。v0.2.1 分段引文校验、失败 trace 保留与无调用恢复仍存在。

演示/模板与内置 LLM 仍可使用。外部驱动不是原 LLM 设置的别名：它需要先在 **连接 Agent** 对本局明确授权。

## 新增的持久化

在用户主动授权后，该 run 才增加 `driver`、`agentJobs`、`agentSubmissions`，schemaVersion 升至 3。原文、旧洞见与模型 trace 不删除。若历史 run 缺少理论快照，首次显式授权时捕获当前已安装版本，不能据此重建早期模型当时实际读过的文本。

新连接信息保存于 `TAO_LAB_HOME/agent/sessions.json`，仅存令牌哈希和非秘密元数据。**网页生成但尚未使用的配对码仅存内存**，重启后需重新生成。

Agent 客户端把长期凭证保存在其本机私有连接文件中，默认位于 `~/.tao-observatory/connections/`；Unix 文件权限 0600。网页生成的配置使用明确路径。不要把该目录、任务领取文件或配对码发布进项目。

## 首次外部接入

选中一局 → 连接 Agent → 保持 Analyst / Guided 默认 → 生成连接凭证 → 复制你的宿主配置 → 让宿主加载该 MCP → 回网页申请六象任务 → 告诉 Agent 领取并用它自己的 AI 提交。

详细说明、CLI 例子和边界：[AGENT-CONNECTION.md](AGENT-CONNECTION.md)。

已经配置的 LLM Key 可以留在旧 `.env`；外部任务通路不使用它，也不会失败后自动回落到内置模型。

## 暂停与重启

角色权限仅在 Agent API 生效，不是 OS 沙箱。配对名称/模型由客户端自述。心跳“桥接在线”不等于 AI 已被唤醒；Guided 模式需宿主主动领取任务。

撤销连接或取消任务均拒绝迟到写入。断连不删除结果、不自动切回模型。手动切回本机驱动才会解除外部模式。

服务重启不自动执行待办。有效的私有凭证可以重新连接；未到期的领取租约可以继续，超时后重新领取。默认租约 15 分钟，可主动续租；每任务最多三次被拒结果。

## 回退

优先使用升级前的完整数据备份回退。**v0.3.0 不认识外部会话/租约/权限模型**，不能依赖它执行 v0.4 的控制边界。

先在 v0.4 撤销连接并停止服务，再用旧版和独立备份启动。不要同时启动新旧服务，也不要手动编辑 JSON 删除新的状态字段以“修复”授权。

## 验证范围

详见本版 [TEST-REPORT.md](TEST-REPORT.md)。本次使用临时数据、固定的外部结果夹具；未调用真实商业模型或登录真实 Codex / Claude Code 账户。没有对用户实际旧数据做写入测试。
