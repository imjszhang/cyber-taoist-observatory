## 不变性检查

`INTEGRITY-v0.3.0.json` 记录了与 v0.2.1 对比的逐文件 SHA-256。宪章、Protocol、来源记录、服务端、证据校验、LLM 配置、原动效模块、配置样例、14 个本机插画/装饰资源逐字节不变。引擎和 CLI 仅修改发布版本文本。没有数据库迁移或隐式重新运行分析。

## 环境与边界

本环境禁止 Chromium 直接导航到 localhost（`ERR_BLOCKED_BY_ADMINISTRATOR`）。未更改浏览器策略。UI 测试采用渲染桥接：将实际 HTML/CSS/JS 与本机图片加载到 about:blank，API 经 Python 转发到真实的临时 Node 服务。

桥接会模拟 History 和 EventSource；因此这里不声称测试了浏览器原生地址栏前进/后退、原生 SSE 网络、或在浏览器 CSP 下的端到端加载。纯路由状态与深链恢复已检查，HTTP 静态资源 / MIME / CSP、SSE 与 CLI 的真实服务接口由 Node 测试覆盖。

没有使用真实商业模型；不能据此保证所有模型兼容或所有真实调用都成功。没有测试 Safari、Firefox、实体移动设备，也不声称通过完整 WCAG 无障碍认证。新增 UI 不构成理论效果或洞见正确性的验证。
